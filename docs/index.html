prompt-architect

A Senior Prompt Engineer layer for Claude Code — translates fuzzy instructions into precision-engineered prompts using the 5-pillar framework

npm · 0.1.0 GitHub Medium simonbalazs.hu

Features

Expand Mode

Turns fuzzy instructions into structured XML prompts — role, context, objective, constraints, review criteria, and first action.

Critique Mode

Scores your prompts across all 5 pillars (0-10 each) with specific findings and concrete fixes.

One-Command Hook

Installs a UserPromptSubmit hook. Runs automatically before every message, no manual invocation needed.

Canonical Template

9-section XML template covering role, context, audience, source material, objective, gated instructions, format, constraints, review criteria.

Per-Request Override

Prefix any message with [full], [light], or [off] to override your default mode.

Zero Config

Set your default mode in CLAUDE.md. Everything else is sensible defaults.

Hook Modes

ModeInvocationWhat It Does
full # prompt-architect-mode: full or prefix [full] Appends the full 5-pillar checklist to every request. Maximum clarity enforcement. Adds ~100 tokens per message.
light # prompt-architect-mode: light or prefix [light] Appends concise structure enforcement: one task per turn, explicit format, self-review. Adds ~30 tokens per message.
off # prompt-architect-mode: off or prefix [off] Clean pass-through. No transformation. Zero token overhead.

The 5 Pillars

Clarity

One task, defined format, explicit constraints

"Could a literal-minded assistant misunderstand?"

Context

Background, audience, source material, goal

"Would the output change if Claude knew WHY?"

Structure

XML tags, numbered steps, examples

"Can Claude instantly parse instructions vs context?"

Advanced

CoT, self-critique, alternatives, persona

"Would drafting then critiquing improve quality?"

Iteration

Review criteria, first action, gated steps

"Single-shot or collaboration?"
